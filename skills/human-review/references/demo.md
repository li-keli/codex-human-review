# 模拟审核：界面偏好

所有内容均为虚构示例，只收集界面偏好，不授权修改设置、实现功能或安装软件。

初始队列只有 `color-theme`，剩余 1 项。第一题使用 `demo-question.json`。

## 第一题 color-theme

唯一决定：演示页面使用深色还是浅色？假设使用者偏好较暗的背景，因此推荐深色，但不预选。

选择深色后关闭本题，激活 `text-size`，剩余 1 项；选择浅色后结束演示，剩余 0 项；暂缓则保留未决事项并停止。自由输入按实际含义处理，含糊时只澄清当前问题。

## 第二题 text-size（仅深色分支）

唯一决定：示例页面使用标准字号还是较大字号？本题只决定文字大小，不改变第一题的配色。

标准字号能在一屏放下更多文字；较大字号便于看清文字，但占用更多空间。推荐标准字号，因为尚未明确放大需求。

选项使用 `standard`（标准字号，推荐）和 `large`（较大字号）。明确选择后结束演示；暂缓则保留未决事项。最后只汇总偏好，不生成文件或修改真实设置。
